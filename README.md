# SafeHood

## 🏘️ Neighborhood Safety App

SafeHood is a community-driven web application designed to help residents stay informed about safety incidents in their neighborhood. Users can report incidents and view recent reports to stay aware of their surroundings.

## Features

- 📝 **Report Incidents**: Submit safety incidents with type, location, description, and severity level
- 👀 **View Incidents**: Browse all reported incidents in an easy-to-read format
- 🔍 **Filter Reports**: Filter incidents by type (theft, vandalism, suspicious activity, etc.)
- 💾 **Persistent Storage**: All reports are saved locally in your browser
- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- 🎨 **Modern UI**: Clean and intuitive user interface

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or installation required!

### Usage

1. Open `index.html` in your web browser
2. View existing incident reports in the "Recent Incidents" section
3. Report a new incident by filling out the form:
   - Select the incident type
   - Enter the location
   - Describe what happened
   - Choose the severity level
   - Click "Submit Report"
4. Use the filter dropdown to view specific types of incidents

## Incident Types

- 🚨 **Theft**: Stolen property or break-ins
- 🔨 **Vandalism**: Property damage or graffiti
- 👀 **Suspicious Activity**: Concerning behavior or presence
- 💡 **Poor Lighting**: Areas with inadequate lighting
- 📝 **Other**: Any other safety-related concerns
